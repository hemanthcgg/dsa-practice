## 🧠 Pattern Mastery Checklist

For every major pattern, I should be able to:

- [ ] Explain the pattern in my own words.
- [ ] Identify when and why it is useful.
- [ ] Explain the brute-force solution first.
- [ ] Derive the optimized approach independently.
- [ ] Analyze time and space complexity.
- [ ] Implement it without copying code.
- [ ] Solve easy and medium variations.
- [ ] Recognize it in an untagged problem.
- [ ] Identify edge cases and situations where it fails.
- [ ] Re-solve important problems after a few days.

## 🏁 Final Objective

My goal is not merely to check every box.

My goal is to become capable of taking an unfamiliar problem,
understanding its structure, developing a brute-force solution,
identifying a suitable optimization, proving why it works,
and implementing it confidently.

**Consistency > problem count. Understanding > memorization.**
